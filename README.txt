PAGETURN LIBRARY MANAGEMENT - FRONTEND

Files included:
- index.html          Homepage
- books.html          Book catalogue with search/category/availability filters
- categories.html     Category directory
- book-details.html   Book details page with sample request interaction
- about.html          About page
- contact.html        Contact form demo
- membership.html     Membership information
- login.html          Login form demo
- register.html       Registration form demo
- style.css           Shared responsive styles
- script.js           Small frontend interactions

HOW TO RUN:
1. Keep all files in the same folder.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.
3. Internet is needed for Google Fonts and external book-cover images.

IMPORTANT:
This is a frontend-only demo. Forms do not send data to a server, login does not authenticate,
registration does not create an account, and book availability is sample data.
Connect a backend/database before using real personal data or real library transactions.
