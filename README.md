# 📚 PageTurn - Library Management Website

**PageTurn** is a modern and responsive Library Management Website frontend developed using **HTML, CSS, and JavaScript**. It provides a user-friendly interface for browsing books, exploring categories, viewing book details, and accessing library membership features.

## ✨ Features

- 🏠 **Home Page** - Attractive landing page with library information.
- 📖 **Books Catalogue** - Browse the available sample books.
- 🔍 **Book Filtering** - Filter books using frontend functionality.
- 🏷️ **Categories** - Explore different book categories.
- 📚 **Book Details** - View book information.
- 🔐 **User Login** - Login page interface.
- 📝 **User Registration** - New member registration interface.
- 💳 **Membership** - Display membership information.
- ℹ️ **About Us** - Information about the library.
- 📩 **Contact Us** - Contact form interface.
- 📱 **Responsive Design** - Supports desktop and mobile screen sizes.
- 🎨 **Modern UI** - Clean layout with interactive elements.

## 🛠️ Technologies Used

- **HTML5** - Structures the website.
- **CSS3** - Provides styling, layouts, and responsive design.
- **JavaScript** - Handles client-side interactions and form feedback.
- **Open Library Covers** - Provides external book cover images.

## 🚀 How to Run the Project

**Step 1: Clone the Repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Open the Project**

Open the project folder in **Visual Studio Code**.

**Step 3: Run the Website**

- Open `index.html` in your web browser.
- Alternatively, install the **Live Server** extension in VS Code.
- Right-click `index.html` and select **Open with Live Server**.

## ⚙️ Current Project Status

- **Version:** 1.0
- **Status:** Frontend Development
- **Database:** Not Connected
- **Backend:** Not Implemented

The current version focuses on the website's user interface and client-side functionality.

- The website uses sample book data.
- Forms display frontend submission feedback.
- Login and registration are frontend demonstrations.
- Book records are not stored permanently.
- No actual borrowing or returning transactions are performed.
